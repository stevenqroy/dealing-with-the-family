Codex · Persona v2

Persona-led v2

Best run first

This version treats the home screen as a shopping-trip decision, not a single product feature. It shows the strongest run, the proof products, the retailer choices, and the need filters earlier.

What changed from v1

  • Hero changed from one product to one retailer run with multiple products.
  • Retailers became decision cards with store headlines instead of a lower list.
  • Needs/category chips moved above the deal list.
  • The store view exposes the play immediately, before the product list.
  • Deal cards now preview where to look, so non-experts can act.

Persona fit

  • Maya sees whether one stop is worth it.
  • Ray sees store strength and multiple finds.
  • Tasha gets a score moment instead of a spreadsheet.
  • Linda gets photos, store, category, and confirmation language.
  • Nicole can start with a need instead of a store.
